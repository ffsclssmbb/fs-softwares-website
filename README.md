# FS Softwares Website

**FS Softwares & TophComm Systems** - Nationwide Business Management Platform

A modern, tech-forward website showcasing 20+ business management solutions for Philippine enterprises across three strategic hubs (NCR, Cebu, Davao).

## 🚀 Tech Stack

- **Framework**: Next.js 14 (React 18)
- **Language**: TypeScript
- **Styling**: TailwindCSS 3
- **Animation**: Framer Motion + Three.js (3D)
- **State Management**: Zustand
- **Forms**: React Hook Form
- **3D Graphics**: Three.js + React Three Fiber
- **UI Components**: Custom + Lucide React Icons

## 🎨 Design System

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ffsclssmbb/fs-softwares-website.git
cd fs-softwares-website

# Install dependencies
npm install

# Create environment file
cp .env.example .env.local

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
